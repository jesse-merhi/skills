# A/B decision deck

Use the deck for multi-screen UI reviews that need item-by-item approval. Put up to five screens in each batch. Copy `assets/ab-decision-deck/` and follow its README to wire the template.

Match the dataset, user role, viewport, theme mode and UI state in each Before/After pair. Annotate the Before screenshot with the item IDs and place a concrete After mock beside it so the reviewer can see the proposed change.

Keep each item ID tied to the same decision across checkpoints. Re-link the current deck at each checkpoint so the reviewer can return to the right batch.
