Code flow · delivery pipeline

A job is acknowledged only after the provider accepts it.

The worker leases one queued job, validates its payload, sends it through the provider adapter, then records the provider receipt before acknowledging the lease.

The invariant A worker crash may cause a safe retry, but it must never mark an unaccepted delivery as complete.

The runtime path

  1. Lease

    worker.ts:run() takes one visible job for 30 seconds.

  2. Validate

    payload.ts:parse() rejects malformed input before any side effect.

  3. Deliver

    provider.send() returns an external receipt or a typed failure.

  4. Commit

    completeJob() stores the receipt, then acknowledges the lease.
