# Pattern sources

The bundled templates draw on these approaches. Consult the sources only when improving the templates themselves:

- [Explorable Explanations](https://explorabl.es/): let a reader change an assumption and see the result.
- [Observable Plot](https://observablehq.com/plot/features/plots): match the visual encoding to the question and data.
- [Tufte CSS](https://edwardtufte.github.io/tufte-css/): keep figures and annotations near the argument.
- [GOV.UK accordions](https://design-system.service.gov.uk/components/accordion/): hide optional detail, not the answer.
- [WCAG reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow): preserve readability on narrow screens.
- [Original HTML effectiveness gallery](https://github.com/ThariqS/html-effectiveness/tree/1787245d94aa680edf18b52027e3f859032776ba/unknowns): examples of comparisons, lessons, and plans.

Templates remain adaptable. Source research is not a second page checklist.
