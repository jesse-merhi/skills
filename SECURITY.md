# Security Policy

## Reporting a Vulnerability

Please report security issues through GitHub private vulnerability reporting or
a private security advisory for this repository. Do not open a public issue for
secrets, credential exposure, or exploitable behavior.

Include the affected file or skill, the impact, and a minimal reproduction when
possible. For credential exposure, include the location and type of credential,
but do not paste live secrets into the report.

## Scope

This repository contains reusable agent skill instructions and helper scripts.
Reports are most useful when they identify leaked credentials, private local
paths, unsafe install behavior, supply-chain risk, or scripts that could mutate
a user's machine without clear consent.
